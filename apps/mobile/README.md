# App móvil (React Native + Expo)

Un solo código para iOS y Android, compilado con EAS Build y publicado en App Store y Google Play.
Usa la misma API y el mismo login que la web; el token se guarda en SecureStore.

Alcance propuesto (por confirmar con Naspeclinic):

- **Gerente:** dashboard KPI, reporte del mes y descarga del PDF.
- **Operador:** agenda del día por sede, cambio de estado de citas y carga de exámenes con la cámara.
